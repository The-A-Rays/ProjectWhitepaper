# ProjectWhitepages
A project for COMP30880 that generates artificial web comics in different languages using integrates LLM API's in order to accommodate easier language learning

To run:
Run the .jar using the console. You can use ctrl + c to kill the program.
 Otherwise, run the jar and kill using task manager
In the console you will see the audio files being generated until it tells
 you the XML is created.
This will take a while, the huge number and variety of api calls from dialogue, 
 translations, captions and audio means there is only so much optimization to be done.
The new xml will be generated as 'newSpecs.xml'
