# ProjectWhitepages
A project for COMP30880 that generates artificial web comics in different languages using integrates LLM API's in order to accommodate easier language learning

To run:
Run the application file 
Then (assuming there are no issues):
Opne a tab in your browser and enter http://localhost:8080/api/openai/generate?prompt=
followed by your prompt
(I've been using 
    http://localhost:8080/api/openai/generate?prompt=Tell me a joke
)
